BREAST CANCER DIAGNOSIS CLASSIFIER
==================================

A machine learning web app (Python + Streamlit) that classifies breast
tumours as Benign or Malignant using the Wisconsin Breast Cancer Dataset.
Built during my IBM SkillsBuild data analyst internship.

NOTE: Educational project only. It is not a medical device and must not be
used for clinical decisions. Please consult a qualified medical professional.


PROJECT STRUCTURE
-----------------
breast_cancer_app/
  app.py               Streamlit entry point and page router
  requirements.txt     Python dependencies
  data/
    breast-cancer.xls  Wisconsin breast cancer dataset
  models/              Trained model .pkl files (created automatically)
  pages/
    eda.py             Exploratory data analysis
    training.py        Model training and evaluation
    comparison.py      Multi-model comparison
    prediction.py      Live single-sample prediction
    about.py           About and documentation
  utils/
    data_loader.py     Data loading and preprocessing
    model_utils.py     Training, evaluation and saving models
    visualizations.py  Plotly / Seaborn chart helpers


HOW TO RUN
----------
You need Python 3.10 or newer, and pip.

  cd breast_cancer_app
  pip install -r requirements.txt
  streamlit run app.py

The app opens at http://localhost:8501


PAGES
-----
Home              Overview and quick-start guide
EDA               Class balance, histograms, box plots, correlation
                  heatmap, pair plot
Model Training    Train any of 6 classifiers, tune hyperparameters, see
                  metrics, ROC curve, confusion matrix, feature importance
Model Comparison  Metrics table and overlaid ROC curves for trained models
Live Prediction   Enter feature values (or pick a random sample) and get a
                  prediction with probability scores
About             Dataset notes, tech stack, references, disclaimer


ALGORITHMS
----------
Logistic Regression     C, solver
Random Forest           n_estimators, max_depth
Support Vector Machine  C, kernel
K-Nearest Neighbours    n_neighbors
Gradient Boosting       n_estimators, learning_rate, max_depth
Decision Tree           max_depth, min_samples_split


TECH STACK
----------
Interface       Streamlit
Data            pandas, NumPy
Machine learning  scikit-learn
Charts          Plotly, Seaborn, Matplotlib
Saving models   joblib
Excel reading   xlrd


DATASET
-------
Wisconsin Breast Cancer Dataset (Diagnostic)
  569 samples, 30 numeric features, 2 classes (Benign / Malignant)
  Features come from digitised fine needle aspirate (FNA) biopsy images
  Source: UCI ML Repository
  Also on Kaggle: "Breast Cancer Dataset" by yasserh

If the bundled .xls file can't be read, the app falls back to the copy of
the same dataset that ships with scikit-learn.
